|------|------|------|
| Java 基础 | 语法、面向对象、集合框架 | ✅ |
| Java 进阶 | Stream、反射、注解 | ✅ |
| 框架基础 | SSM (Spring + SpringMVC + MyBatis) | ✅ |
| SpringBoot | 自动配置、starter、整合中间件 | ✅ |
| 微服务 | SpringCloud、Nacos、分布式事务 | ✅ |
| 中间件 | Redis、RabbitMQ、Elasticsearch | ✅ |
| 项目实战 | 企业级项目开发 | ✅ |
| 面试专题 | 框架面试题、面试经验 | ✅ |
