# Blog — VitePress + Teek Theme

## Commands

```bash
pnpm install        # install dependencies (pnpm 8, Node 22)
pnpm dev            # local dev server (vitepress dev docs)
pnpm build          # compress images THEN build → docs/.vitepress/dist/
pnpm preview        # preview production build
pnpm compress       # run image compression only (scripts/compress-images.mjs)
```

**Important:** `pnpm build` runs image compression (`sharp`) before VitePress build. Images in `docs/public/` are recompressed in-place (lossy — PNG quality 80, JPEG quality 80 + mozjpeg). Do not run `pnpm build` unless you intend to recompress images.

## Architecture

- **Static blog** built with VitePress + `vitepress-theme-teek`
- Content: `docs/` (Markdown with YAML frontmatter)
- Config: `docs/.vitepress/config.mts` — uses `defineTeekConfig()` then passes result to `defineConfig({ extends: teekConfig })`
- Theme entry: `docs/.vitepress/theme/index.ts` — imports Teek + chalk CSS overrides
- `docs/.vitepress/teekConfig.mts` exists but is **unused** — `config.mts` is the single source of truth
- Sidebar: auto-generated by Teek (`sidebar: {}`)
- Mermaid: supported via `vitepress-plugin-mermaid` (both `MermaidMarkdown` md plugin and `MermaidPlugin` vite plugin)

## Content Structure

- All content in Chinese (简体中文)
- Category dirs under `docs/`: `python/`, `ai/`, `devops/`, `java/`, `database/`, `projects/`
- Static assets: `docs/public/`
- Homepage: `docs/index.md`
- Gitignored: `docs/.vitepress/dist/`, `docs/.vitepress/cache/`

## Deploy

- Push to `main` → GitHub Actions (`.github/workflows/deploy.yml`) → GitHub Pages
- CI uses pnpm 8 + Node 22, runs `pnpm install && pnpm build`, deploys `docs/.vitepress/dist/`
