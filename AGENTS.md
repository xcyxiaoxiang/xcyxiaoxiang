# Blog — VitePress + Teek Theme

## Commands

```bash
pnpm install        # install dependencies (pnpm 8, Node 22)
pnpm dev            # local dev server
pnpm build          # production build → docs/.vitepress/dist/
pnpm preview        # preview production build
```

## Architecture

- **Static site blog** built with VitePress using the `vitepress-theme-teek` theme
- Content source: `docs/` (Markdown files with YAML frontmatter)
- Theme config: `docs/.vitepress/config.mts` (main, uses `defineTeekConfig`)
- Theme entry: `docs/.vitepress/theme/index.ts` (extends Teek)
- `docs/.vitepress/teekConfig.mts` exists but is **unused** — `config.mts` is the active config
- Sidebar is auto-generated by Teek theme (`sidebar: {}`)
- Mermaid diagrams supported via `vitepress-plugin-mermaid`
- `docs/.vitepress/dist/` is build output (gitignored)

## Conventions

- All content is in Chinese (简体中文)
- Static assets go under `docs/public/`
- Blog posts organized by category subdirectories under `docs/` (python, java, devops, ai, database, projects)
- Deploy: push to `main` triggers GitHub Actions → GitHub Pages
